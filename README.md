# skate-clip-cutter

Windows desktop only.

A simple tool that processes raw footage into separated clips based on a person being detected.

Download: https://github.com/sqidz/skate-clip-cutter/releases/latest

Unzip the folder and double-click Skate Clip Cutter.bat.

If Windows blocks it: right-click the folder, Properties, Unblock.
